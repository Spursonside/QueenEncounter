# V12: 낮은 발 궤적으로 5m 반복 완주

## 결과

분리된 UE 프로세스 2개로 3세대 × 6개체 = 18개 후보를 평가했다. 16개가 5m 보행 기준을 통과했다(같은 부모 재평가 포함). 해당 학습 실행의 실제 경과 시간은 187.82초였다. 코드 작성·디버깅·추가 검증 시간은 별도다. 이는 병렬/직렬 속도 비교 벤치마크가 아니다.

실패 개체를 부모로 선택한 경우는 0건이며, 원본 JSON과 모든 부모 ID를 대조했다.

두 정책을 보존했다. 각각 다른 UE 실행이 없는 상태에서 **새 프로세스로 3회씩 순차 재생**했고 모두 5m를 완주했다. 같은 정책의 3회 측정값은 동일했다. 이후 화면 렌더링/영상 촬영에서도 동일한 결과가 재현됐다.

| 항목 | 빠른 정책 | 지지 발 평균 이탈이 작은 정책 |
|---|---:|---:|
| 5m 완주 시간 | 53.47초 | 73.37초 |
| 평균 몸체 높이 | 6.99m | 6.99m |
| 평균 몸체 기울기 | 0.49° | 0.30° |
| 최대 발 여유 높이 | 1.10m | 0.92m |
| 접지 발 중심 속도 | 0.22m/s | 0.15m/s |
| 지지 발 평균 위치 이탈 | 11.10cm | 6.31cm |
| 지지 발 최대 위치 이탈 | 52.26cm | 38.16cm |
| 유효 발 들기/착지 | 19.00회 | 26.00회 |

두 정책 모두 직립 비율 100%다. **미끄러짐과 굴러감이 완전히 0인 상태는 아니다.** 지지 발 이탈은 첫 접촉 지점 기준 수평 위치 변화이며, 착지 과정의 정착/구름도 포함한다. 접촉 힘을 측정한 값은 아니다.

이번 검증은 같은 절차적 지형, 같은 출발점, 여섯 다리, 5m 구간이다. 다른 지형 seed·다리 파괴·50m 장거리의 성공으로 확대 해석하지 않는다.

## 바뀐 제어

- 실제 발 위치와 실제 관절 축으로 야코비안을 계산하고, 감쇠 최소제곱으로 관절 목표를 보정한다. 예상 발 위치만으로 제어하던 오차 누적을 줄였다.
- 이동하는 발은 월드 착지점을 추적하고, 지지 다리는 목표 몸체 자세를 지탱한다. 몸체나 발의 위치를 실행 중 직접 옮기지 않는다.
- 발의 속도를 측정해 제동하는 항을 추가했다. 기본 발 높이 목표는 65cm이고 50~80cm 범위를 탐색한다. 실제 높이는 물리 결과라 목표와 다를 수 있다.
- 이전 발의 접지가 0.15초 유지된 것을 확인해야 다음 다리를 든다. 4초 내 착지하지 못하면 실패 처리한다.
- 몸체 기울기가 60도를 넘어가면 전복 실패로 처리한다. 전복 이후 밀려난 거리를 보행 성과로 쓰지 않는다.
- 물리 서브스텝 최대 간격을 1/120초로 설정하고, 제어 중 강체를 깨워 모터 목표가 수면 상태에서 무시되지 않게 한다.
- 선택적 발목 보정은 발이 종아리를 따라 기울며 구르는 것을 줄이도록 수평 자세를 목표로 삼는다. 관절 가동 범위와 유한 토크를 유지한다.
- `world_level_ankle` 설정을 정책에 저장하고 재생 시 복원한다.

보행 순서는 규칙 기반 wave gait이며, **시간·보폭·발 높이·속도 제동·관절 강성의 5개 변수는 Gaussian 진화 탐색**으로 조정한다. 신경망/PPO/Isaac Lab 런타임을 사용한 학습이라고 표기하지 않는다. 기존 94개 저장 슬롯 중 활성 인덱스는 0,1,2,3,37이다.

## 발목 보정의 동일 정책 비교

동일한 `candidate_0002_04` 유전자를 보정 전후로 실행했다.

- 보정 전: 69.72초, 평균 이탈 8.67cm, 최대 이탈 29.84cm.
- 보정 후: 73.37초, 평균 이탈 6.31cm, 최대 이탈 38.16cm.

보정 후 평균 이탈은 줄었지만 최대 이탈과 완주 시간은 증가했다. 모든 지표가 좋아진 것으로 표현하지 않는다. 빠른 정책과 이 정책은 유전자도 서로 다르므로 두 정책 사이의 차이 전체를 발목 보정 하나의 효과로 해석하지 않는다.

## 병렬 평가와 부모 선택

`TrainIsolatedGait.py`는 후보마다 **새 UE 프로세스/물리 월드**를 만들며 동시에 최대 2개 실행한다. 한 물리 월드에 후보를 겹쳐 놓지 않는다. 제어 주기는 60fps 고정으로 실행한다.

부모는 물리 실패 없음, 5m 도달, 직립 비율 ≥90%, 접지 발 중심 속도 ≤0.30m/s, 접지 발 각속도 ≤0.60rad/s, 보행 단계 일치율 ≥75%, 모든 다리의 유효 들기/착지 ≥1회를 만족해야 한다. 유효 걸음에는 0.15초 이상 공중 체류, 25cm 이상 여유 높이, 25cm 이상 수평 이동과 재접지가 필요하다.

세대별 부모는 통과 후보 중 기존 평가 점수가 높은 최대 4개다. 부모가 없으면 실패 유전자를 버리고 새 집단을 만든다. 시연할 빠른 정책은 통과 후보 중 최대 발 높이 ≤1.5m인 후보의 완주 시간으로 별도 선택했다. 세대별 속도가 단조롭게 개선됐다고 주장하지 않는다.
