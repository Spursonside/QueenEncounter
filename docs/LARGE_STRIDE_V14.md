# V14 몸집에 맞는 큰 보폭

V13의 5m 27.38초는 기존보다 빨랐지만, 높이 7m인 퀸의 이동으로는 여전히 느렸다. 주원인은 작은 발 전방 배치 거리(약 1.19m)로 계산한 몸체 목표 속도가 약 0.256m/s였다는 점이다. 평가의 최소 20초 조건 역시 그보다 빠른 완주를 막고 있었다.

## 변경

- 발 전방 배치 거리에 새 유전자 8의 배율 `1 + 2.5*max(0,g8)`을 곱한다. V13 정책의 추가 변수가 0이면 기존 값이다.
- 이동하는 발의 위치 제어 이득·위치 오차 처리 범위·목표 관절 각속도 한계에 `1 + max(0,g9)`를 곱한다. 발을 멀리 놓는 만큼 실제 관절이 목표를 따라갈 수 있게 한다. 지지 다리의 이득은 바꾸지 않는다.
- 이동 시험의 최소 20초 조건을 제거했다. 모든 살아 있는 다리가 실제로 뜨고 착지해야 한다는 조건, 직립·구르기·접지 검사, 목표 거리는 유지한다. 제자리 학습은 20초 기준을 유지한다.
- 유효 걸음의 이륙점→착지점 수평 이동 거리를 평균/최대로 기록한다. 이는 몸체 이동 거리나 중립 위치 대비 발 배치 거리와 다르다.
- 착지 대기 초과와 몸체 자세/범위 이탈 등 실패 사유를 기록한다. 실패한 움직임은 부모로 남기지 않는다.

보폭만 키운 후보들은 관절 추종이 늦어 후진하거나 착지에 실패했다. 이동 발의 추종을 빠르게 한 후보에서 큰 보폭과 정상적인 완주가 함께 나왔다.

## 품질 기준의 변경

큰 보폭에서는 접지 직후 자리잡기 동작도 빨라진다. V13의 보수적인 접지 발 중심 속도 상한 0.2165m/s 대신 기본 보행 판정의 0.3m/s를 사용한다. 평균 접지 변위 11.1cm, 최대 변위 52.3cm, 발 최고 높이 1.5m 상한은 그대로 유지한다. 모든 값과 상한은 세대 선발 JSON에 기록된다. 속도가 더 빨라졌다는 이유만으로 평균/최대 변위를 더 허용한 것은 아니다.

접지는 지형 레이와 구형 발 반경으로 추정한다. 발 중심 속도와 실제 접지 변위는 서로 다른 지표이며 착지 후 자리잡기/굴림을 포함한다. 동영상 없이 수치와 로그만 검증했으므로 시각적으로 자연스러워졌다고 단정하지 않는다.

## 범위

가우시안 진화 탐색으로 관절 제어 변수를 학습한다. 신경망 PPO나 Isaac Lab 실행이 아니다. 최대 두 개의 독립 UE 물리 프로세스를 병렬로 실행하고, 동일한 절차적 지형과 시작점에서 비교한다. 한 번에 한 다리를 드는 방식이며, 두 다리 동시 이동과 다리 손실은 이번에 검증하지 않았다.

## 검증 결과

| 항목 | V13 | V14 |
|---|---:|---:|
| 5m 소요 시간 | 27.38초 | 14.22초 |
| 발 전방 배치 거리 | 1.19m | 2.38m |
| 평균 접지 변위 | 7.66cm | 4.96cm |
| 최대 접지 변위 | 41.51cm | 38.46cm |
| 발 최고 높이 | 0.68m | 0.63m |

V14는 유효 걸음당 실제 수평 발 이동 거리 평균 3.30m, 최대 4.71m다. 초기 3초 정착 시간을 포함한 결과다. 세 번의 독립 5m 반복 실행에서 동일한 측정값을 얻었다.

12개 조합 비교와 2세대 16회 추가 평가를 수행했다(재평가 포함). 기본 완주 통과는 총 15회/28회이며, 추가 접지 품질 기준과 점수로 부모를 선발했다. 실패 부모 선발은 독립 감사에서 0건이었다. 첫 조합 비교는 발 중심 속도 상한 0.2165m/s를 사용해 부모가 0개였고, 그중 기본 완주한 14.22초 후보를 0.3m/s 기준으로 다시 검토해 다음 탐색의 초기 정책으로 사용했다. 미완주 후보를 이월한 것은 아니다.

- 15m 독립 확장 검증(1회): 기본 완주 통과, 종료 전방 변위 15.01m, 37.23초. 평균 접지 변위 17.01cm, 최대 75.00cm. 추가 접지 품질 기준 미통과. 실패 사유 필드: `없음`.
- 50m 독립 확장 검증(1회): 기본 완주 실패, 종료 전방 변위 6.02m, 70.15초. 평균 접지 변위 21.32cm, 최대 275.07cm. 추가 접지 품질 기준 미통과. 실패 사유 필드: `body_pose_or_bounds`.

장거리 완주 여부와 접지 품질 통과 여부를 구분한다. 15m에서는 평균 접지 변위 17.01cm, 최대 75cm로 단거리보다 커졌다. 큰 보폭에서 장시간 지지하는 발의 위치 이탈을 줄이는 작업이 남아 있다. 다른 지형 시드나 다리 손실에 대한 일반화 결과는 아니다.
