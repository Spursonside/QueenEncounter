# 몸체 5m/s 목표 실험 V15

**목표 미달. 정상적인 50m 완주와 5m/s 유지에 성공한 정책은 없다.**

## 목표와 계측

대상은 발끝 속도가 아닌 몸체의 실제 전진 속도다. 목표 속도의 기존 3m/s 상한을 확장하고 5m/s를 명령했다. 처음 10m까지의 도달 시간을 별도로 측정하며, 이후 구간의 평균 전진 속도와 4.5~5.5m/s 범위에 있었던 시간 비율을 기록한다. 초기 3초 정착 후 1초 단위 몸체 속도도 JSON에 저장한다.

성공 조건은 정상 보행으로 50m 완주, 유지 구간 5초 이상, 유지 평균 4.5~5.5m/s, 그 범위에 있었던 시간 비율 80% 이상이다. 미완주·넘어짐·미끄러짐·일시적으로 튕겨 나간 이동은 성공으로 인정하지 않는다. 가속 구간이 포함된 50m 총 시간을 단순히 10초와 비교하지 않는다.

## 구현과 비교

서로 반대편인 두 다리를 `(0,5) → (2,3) → (1,4)` 순서로 함께 움직이고, 두 발의 착지를 확인한 뒤 다음 쌍으로 넘어간다. 네 지지 다리가 남는 방식이다. 목표 속도와 주기로 발 전방 배치 거리를 정하고, 큰 보폭을 추종할 수 있도록 관절 속도 한계를 확장했다. 원래 관절 각도 한계는 유지한다. 몸체 위치를 직접 옮기거나 외력으로 끄는 방식은 추가하지 않았다.

1. `v15_pair_sweep01`: 짧은 가속과 목표 발 속도/몸체 속도를 반영하는 제어. 5m/s·50m 12개 조합 모두 실패.
2. `v15_pair_ramp01`: 가속과 보폭 확대를 12초에 걸쳐 적용하고 제어 강도를 낮춤. 5m/s·50m 12개 모두 실패.
3. `v15_pair_feedback01`: 속도 예측 입력을 제거하고 실제 발 위치/속도 피드백, 제약 풀이 반복 횟수를 강화. 5m/s·50m 12개 모두 실패.
4. `v15_pair_calibration01`: 마지막 방식에서 1m/s·5m 진단 6개. 모두 실패. 5m/s 달성 시험 수에는 포함하지 않는다.

최종 코드의 실험 제어 버전은 `v15_paired_feedback`이다. 앞선 두 실험의 정책은 제어 의미가 다르므로 최종 로더에서 그대로 재생하지 않는다. 기본 보행은 기존 V14 정책을 사용하며, 실험 모드는 유전자 10이 0.5보다 크고 다리가 모두 있을 때만 켜진다. 다리가 손실된 상태의 새 보행은 검증하지 않았다.

## 실제 결과의 의미

5m/s 목표 시험 36개 중 정상 50m 완주 0개, 5m/s 유지 성공 0개다. 별도의 저속 진단 6개도 통과하지 못했다. 원자료의 전방 변위와 속도에는 불안정하게 밀리거나 튕긴 값이 있으므로 최장 이동/최고 속도를 성과로 표기하지 않는다.

낮은 속도에서도 새 방식이 실패했으므로, 현재 결과만으로 물리 모델의 최고 속도가 5m/s 미만이라고 단정할 수는 없다. 새 지지 다리 제어와 착지 전환 자체를 안정화해야 한다는 진단이다. 가속/제어 강도 조절만으로 해결되지는 않았다.

모든 부모 목록을 별도로 감사했다. 통과한 부모가 없었고 실패 유전자를 물려주지 않았다. 따라서 이번 실행을 여러 세대의 성공적인 진화 학습으로 표현하지 않는다. 새 제어 방식의 초기 집단 비교와 진단 단계다. 사용한 알고리즘은 가우시안 변수 탐색이며 신경망 PPO나 Isaac Lab 실행이 아니다.

## 기록과 실행

영상은 촬영하지 않았다. `v15_speed_trials.csv`에 후보별 측정값, `v15_speed_summary.json`에 결과/감사 요약, 각 `LearningRuns/v15_*` 폴더에 정책·선발 목록·엔진 로그를 보존했다. 해당 기록은 성공 포트폴리오가 아니라 실패 원인과 개선 과정의 증거다.

```powershell
python Scripts/TrainIsolatedGait.py --run new_5mps_trial --paired --paired-sweep --plant-feet --goal 50 --speed 5 --workers 2 --population 12 --generations 1 --max-stance-speed .3 --episode 45
python Scripts/audit_gait.py LearningRuns/new_5mps_trial
```

현재 같은 조건을 반복 실행해도 달성을 보장하지 않는다. 다음 구현 과제는 지지 다리의 몸체 이동 보상과 착지 전환을 분리하여 안정화한 뒤, 완주 가능한 단계에서 속도를 높이는 것이다. 목표는 계속 몸체 5m/s다.

## 기존 보행과 검사

기존 V14의 계산 순서를 보존해 최종 빌드에서 5m 14.2166초, 평균 접지 변위 4.9647cm, 최대 38.4636cm를 재현했다. 실험 전 수치와 동일하다. 초기 회귀 검사에서 접지 변위가 달라진 기록도 `v15_baseline_regression01`에 보존했다. 수정 후 결과는 `v15_baseline_regression02`다. 에디터 빌드와 자동 테스트 두 개(유지 속도 판정 추가 포함), 부모 선발 감사가 통과했다. 이는 5m/s 보행 성공을 뜻하지 않는다.
