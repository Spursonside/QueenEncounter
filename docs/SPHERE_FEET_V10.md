# 구형 고마찰 발 재학습

발 외형과 실제 단순 충돌을 Sphere로 바꿨다. 지름은 약 1.426m이고 세 축에 동일한 스케일을 사용한다. 런타임에서 구형 충돌 요소 1개를 확인했다. 발목은 구의 상단에 연결하며 기존 발목 각도 제한과 모터를 유지하므로 자유 회전하는 바퀴는 아니다.

구형 발 높이 증가분만큼 발목 위치를 올려 초기 접촉 높이를 맞췄다. 발의 동마찰 3, 정마찰 4, Max 결합, 기울기 감점 2, 각속도 감점 0.75, 상하 흔들림 감점 1을 유지한다. 몸체 목표 높이 7m, 이동 목표 50m, 제한 시간 150초다.

## 사전 검증

- UE 5.8.2 Editor 빌드 성공.
- 실제 구형 충돌 로그: `collision_spheres=1 diameter_cm=142.59`.
- 150.007초 기본 자세 시험: 평균 높이 6.811m, 높이 표준편차 0.0042m, 직립 판정 비율 100%.
- 전방 변위 -0.557m로 정지 드리프트가 완전히 사라진 것은 아니다.
- 원자료: `LearningRuns/v10_sphere_standing/replay_result.json`.

## 재학습 조건

새 난수 시드 20260907로 4세대×16개체를 평가한다. 이전 미완주 정책은 초기값으로도 사용하지 않는다. 모두 미완주하면 유전자를 폐기하고 새 후보를 생성한다. 완주 후보가 생긴 경우에만 점수 상위 최대 4개를 부모로 선택한다.

```powershell
.\Scripts\TrainPhysics.ps1 -Terrain -Generations 4 -Population 16 -Episode 150 -GoalMetres 50 -Seed 20260907 -RunName my_sphere_run
```

원자료: `LearningRuns/v10_sphere_retrain_01/`. 모든 개체의 유전자와 측정을 `candidate_세대_개체.json`에 보존하므로 최고 점수와 별도로 실제 최장 이동 개체를 재생할 수 있다. 부모 선택은 `selection_세대.json`으로 별도 기록한다.

## 4세대 시험 결과

64개체 평가 완료: 50m 완주 0, 물리 종료 조건에 해당한 실패 5, 미완주 시간 초과 59. 실패 개체의 부모 선택 위반은 0건이었다. 모든 세대가 부모 없는 새 집단으로 다시 시작했으므로, 성공 유전자를 누적한 학습이 아니라 새 조건에서의 독립 후보 탐색 결과다.

원시 최대 변위는 36.112m지만 평균 기울기 133.39°·직립 판정 비율 19.3%로 뒤집힌 구간이 포함된다. 영상 후보는 물리 실패 없음, 직립 판정 비율 90% 이상, 평균 기울기 35° 미만인 개체 중 가장 멀리 이동한 0세대 15번을 선택했다. 이 기준은 영상 선정용이며 부모 선별 규칙을 완화하지 않았다.

선택 개체의 평가 당시 전방 변위는 21.494m, 직립 판정 비율 100%, 평균 몸체 높이 6.949m, 평균 기울기 4.406°였다. 50m 미완주이므로 번식하지 않았다.

모든 64개체의 정책 파일과 CSV 측정값 일치 및 Sphere 설정을 검사했다. 결과: `selection_audit.json`, `replay_selection.json`.
