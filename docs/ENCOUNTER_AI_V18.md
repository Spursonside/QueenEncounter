# V18 수동 리셋·디버그·전투 AI·편측 손실 점프

2026-09-07 / UE 5.8.2

## 실행과 조작

`Scripts/PlayAdaptiveQueen.ps1 -Player`로 실행합니다. 플레이어 모드는 이제 고정 시연 경로 대신 AI를 사용합니다. 50m 도달, 시간 경과, 플레이어 사망으로 자동 리셋하지 않습니다. R을 눌러야 처음 상태로 돌아갑니다. 기존 자동 보행 검사 모드의 반복 동작은 별개입니다.

- WASD 이동, 마우스 조준·좌클릭 사격, Shift 달리기, Space 점프.
- F2 디버그 표시 전환.
- F4 다음 다리 하나, F5 앞 네 다리, F6 왼쪽 세 다리, F7 오른쪽 세 다리 파괴.
- R 수동 리셋.

## AI 구성

이번 구현은 C++ 우선순위 상태 머신(FSM)입니다. Unreal Behavior Tree 에셋을 만든 것은 아닙니다. `QueenEncounterAI.cpp`의 `Think`가 감지·상태 선택·이동 요청을 담당하고, 기존 지형 IK가 이동을 실행합니다.

1. 배회: 출발점 주변 목적지를 주기적으로 갱신합니다.
2. 감지: 45m 안의 살아 있는 플레이어와 시야 차단을 검사합니다.
3. 추적·공격: 먼 경우 접근하고 약 24m 안에서는 정지합니다. 3초 간격으로 공격하며 마지막 1초는 조준을 고정한 예고선을 보여줍니다. 실제 레이 판정으로 명중 시 HP 15 감소, 지형에 막히거나 플레이어가 피하면 빗나갑니다.
4. 수색: 시야를 잃으면 마지막 발견 위치를 최대 5초 추적합니다.
5. 도주: 다리 3개 이상 손실 시 공격보다 우선합니다. 플레이어 반대 방향으로 점프한 뒤 회복·저자세 이동을 반복합니다.
6. 모든 다리 손실: 점프와 이동을 멈춥니다.

## 편측 손실의 불안정한 점프

남은 오른쪽 다리 수에서 왼쪽 수를 뺀 값을 3으로 나눠 불균형을 계산합니다. 왼쪽 세 다리 손실은 +1, 오른쪽은 -1, 앞 네 다리 손실은 0입니다.

- 최대 24°만큼 도주 방향이 비뚤어집니다.
- 비행 중 최대 22°의 추가 좌우 기울기, 착지까지 최대 18°의 추가 방향 회전을 적용합니다.
- 회복 대기 시간은 대칭 손실 4초, 완전한 편측 손실 7초입니다.
- 점프는 기본 1.6초·높이 2.2m·거리 8.5m의 절차적 궤적입니다. 한 다리만 남으면 거리는 4.2m입니다.
- 착지 발 위치의 지형과 몸체 비행 경로를 사전 검사하고, 이동 중에도 몸체 충돌을 검사합니다.

이는 좌우 추진력 불균형을 표현하는 연출 규칙입니다. 관절의 물리적 추진력에서 자연 발생한 점프나 학습한 정책은 아닙니다. 떨어진 다리에는 기존 Chaos 물리를 유지합니다.

## 디버그 표시

현재 행동, 실제 속도·목표 속도, 몸체 roll/pitch, 플레이어 HP, 공격·점프 횟수와 각 다리의 상태를 표시합니다. 관절은 몸체 기준 첫 축의 yaw 및 이어지는 네 연결부의 굽힘 각도를 도 단위로 계산합니다.

노란 표시와 수직선은 보행 제어에 쓰는 몸체 중심과 지면 투영입니다. 물리 질량 합성으로 계산한 무게중심은 아니며 화면에도 `CONTROL COM (kinematic)`이라고 명시합니다. 초록색은 지지 영역과 다리, 하늘색은 들어 올린 다리입니다. 다수가 손실된 저자세에서는 지지 영역에 기존 연출용 몸통 지지 영역이 포함됩니다.

## 검증과 한계

`Scripts/VerifyEncounterAI.py --run 새폴더명`으로 UE 프로세스 2개를 병렬 실행합니다. 테스트는 플레이어 위치·체력을 통제하며, 처음 8초는 감지 범위 밖, 이후 근거리, 25초에 손실을 적용하고 75초에 테스트 프로세스만 종료합니다. 실제 플레이어 시연에는 이 타이머와 체력 복구가 없습니다.

[AI 최종 검사](../LearningRuns/v18_release/verification.json): 왼쪽·오른쪽 각 세 다리 손실, 앞 네 다리 손실, 전체 손실을 검사했습니다. 좌우 편측은 각 6회 점프·6회 착지, 대칭 손실은 9회 점프·9회 착지, 전체 손실은 점프 0회입니다. 모두 감지와 5회 공격·실제 HP 감소를 확인했고, 75초까지 자동 리셋 없이 유지됐습니다.

[기존 보행 회귀 검사](../LearningRuns/v18_gait_regression/verification.json)는 정상 전진·회전·앞 네 다리 손실·벽 충돌 중단을 별도로 확인합니다. 기존 `passed` 필드는 50m 보행 벤치마크용이며, 연속 전투의 성공 판정은 AI 검증 파일의 바깥쪽 `passed`를 사용합니다. 보행 통계의 기울기·발 지지 수는 지상 구간 통계이며 비행 전체의 최댓값으로 해석하면 안 됩니다.

렌더링 화면에서 행동·관절 각도·중심·지지 영역, 실제 공격에 의한 HP 감소를 확인했습니다. 화면의 기존 `/50m` 표기는 보행 계측 표시로 남아 있지만 플레이어 모드의 종료 조건은 아닙니다.

복잡한 장애물 회피용 NavMesh 경로 탐색은 아직 없습니다. 지형 끝이나 몸체 충돌에서는 안전하게 멈추며 R로 리셋합니다. 전투 모드는 보행 벤치마크의 전역 누적 품질 임계치로 자동 종료하지 않으므로, 임의 지형·손실 조합의 관절 도달 범위와 다리 간섭은 추가 확인이 필요합니다. 이번 네 조건에서는 IK 오차와 살아 있는 다리 간격 검사를 통과했습니다.
