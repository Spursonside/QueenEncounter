# V19 큰 발구름·점프 및 네 다리 고자세

2026-09-07 / UE 5.8.2

## 변경

- 점프 준비 0.85초: 발을 최대 1.6m 들어 내려찍고, 몸을 최대 1.1m 압축한 뒤 마지막 0.25초에 다리를 펼쳐 밀어냅니다. 접촉 순간 짧은 원형 디버그 효과와 `STOMP → COMPRESS → DRIVE → AIRBORNE` 상태 표시를 추가했습니다.
- 비행 시간 1.6초 → 2초, 기준 궤적 대비 상승량 2.2m → 5m, 수평 거리 8.5m → 14m. 한 다리만 남으면 수평 거리는 6.5m입니다. 편측 손실 시 기울기·방향 오차·긴 회복 시간은 유지합니다.
- 두 다리 손실 시 무조건 저자세로 전환하던 규칙을 제거했습니다. 네 다리가 남으면 목표 몸체 높이 6.4m, 세 다리 이하에서만 기존 저자세 회복을 사용합니다.
- 높은 네 다리 자세는 짧은 동적 지지 전환을 허용합니다. 지지 영역 이탈 누적 시간과 연속 시간을 모두 기록하며, 보행 검사의 네 다리 조건에서는 연속 0.65초 초과 시 실패합니다. 이전의 누적 2초 기준과 같지 않습니다.

현재 보행과 점프는 절차적 IK·몸체 제어입니다. 물리 모터 힘을 키우거나 물리 질량을 줄인 결과는 아니며, 발구름도 지면에 물리 충격량을 전달하는 방식이 아닙니다.

## 검증

[고자세 검사 원자료](../LearningRuns/v19_stance_release/verification.json): 앞 두 다리(9), 왼쪽 앞·중간(3), 뒤 두 다리(36), 오른쪽 앞·중간(24) 손실의 네 조건에서 실제 순변위 50m를 완주했습니다. 손실 이후 안정 구간의 최소 몸체 높이는 약 6.30~6.31m, 목표 높이는 6.4m입니다. 연속 지지 이탈 최댓값은 약 0.292초였으며, IK 오차·살아 있는 다리 간 간격·접지 이탈·몸체 기울기 검사도 통과했습니다. 정적인 지지 영역 안에 항상 머문다는 뜻은 아닙니다.

[최종 점프 검사](../LearningRuns/v19_jump_release/verification.json): 좌우 각 세 다리 손실과 앞 네 다리 손실에서 몸체 위치를 측정한 상승량 5.00m, 수평 이동 14.00m를 확인했습니다. 좌우 편측은 75초 시뮬레이션 동안 각각 5회 발구름·5회 점프·5회 착지, 앞 네 다리 손실은 6회 발구름·6회 점프·5회 착지였습니다(검사 종료 때 마지막 점프 진행 중). 전체 손실은 점프 0회입니다. 자동 리셋은 없습니다.

초기 높은 자세의 엄격한 정적 지지 기준 검사는 약 13~15m에서 누적 지지 이탈로 실패했습니다. `v19_four_leg`에 이 결과를 보존했으며 성공으로 표기하지 않습니다. 정상 여섯 다리 전진은 같은 변경에서 50m·순항 5m/s를 유지했습니다.

## 실행

`Scripts/PlayAdaptiveQueen.ps1 -Player`
