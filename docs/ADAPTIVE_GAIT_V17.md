# V17 외형 복원·방향 이동·손실 보행

2026-09-07, Unreal Engine 5.8.2. 최종 24개 검증 조건 모두 통과. 영상은 추가 촬영하지 않았습니다.

## 변경 사항

- V14/V15의 두꺼운 사각 다리와 관절 하우징, 납작한 몸통, 14개 분할 장갑을 복원했습니다. 5m/s 보행에 필요한 넓은 발 간격은 유지했습니다.
- 정상 전진 5m/s, 후진 3m/s, 좌우 이동 2m/s, 제자리 회전 및 이동 중 회전을 구현했습니다. 회전 시 미래 몸체 방향까지 예측해 발을 착지시킵니다.
- 다리 두께를 포함하는 캡슐로 서로 다른 살아 있는 다리의 간격을 120Hz로 검사합니다. 보폭·다리 배치·들어 올리는 순서로 겹침을 줄였으며, 검사에서 간격이 음수이면 실패 처리합니다. 이는 임의의 장애물에서 자동으로 우회하는 플래너는 아닙니다.
- 한 다리 손실 시 남은 발 쪽으로 무게중심 연출을 옮기고 약 2.5m/s로 감속합니다. 발 하나를 들기 전에 남은 지지 영역을 확인합니다.
- 두 개 이상 손실 시 낮은 자세로 전환합니다. 앞쪽 네 다리를 잃으면 앞을 기울이고 뒤쪽 두 다리로 약 0.65m/s로 이동합니다. 모든 다리를 잃으면 멈춥니다.
- 분리된 다리는 관절 제약을 연결한 Chaos 물리 부품으로 떨어집니다. 플레이어 사격의 부위 피해도 새 퀸에 연결했습니다.
- F4/F5와 엔진 기본 디버그 표시 키의 충돌을 제거했습니다. 프레임 마지막의 극소 시간 조각 때문에 속도가 0으로 표시되던 현상도 고정 120Hz 누적 시간 처리로 수정했습니다.

## 재현

프로젝트 폴더에서 PowerShell로 실행합니다.

```powershell
# 퀸 직접 조작
./Scripts/PlayAdaptiveQueen.ps1
# 전진 → 왼쪽 이동 → 회전 → 오른쪽 이동 → 전진
./Scripts/PlayAdaptiveQueen.ps1 -Scenario change
# 앞 네 다리 손실, 언덕에서 출발
./Scripts/PlayAdaptiveQueen.ps1 -Scenario forward -DamageMask 27 -Hills
# 기존 플레이어를 배치한 사격 테스트 모드
./Scripts/PlayAdaptiveQueen.ps1 -Player
# 새 이름의 기록 폴더에 독립 UE 프로세스 두 개로 병렬 검사
python ./Scripts/VerifyAdaptiveQueen.py --run my_v17_check
```

직접 조작: W/S 전진·후진, A/D 좌우, Q/E 회전, F4 다리 하나 파괴, F5 앞 네 다리 파괴, R 초기화. 자동 시나리오에서도 F4/F5/R을 사용할 수 있습니다. 자동 시나리오의 이동 방향은 스크립트가 제어합니다. 플레이어 모드의 WASD/마우스는 플레이어를 조작합니다.

다리 번호는 왼쪽 앞·중간·뒤가 0·1·2, 오른쪽 앞·중간·뒤가 3·4·5입니다. DamageMask는 해당 비트의 합이며, 지정 손실은 시작 3초 후 적용합니다.

## 화면 확인과 성능

렌더링 화면에서 정상 5.00m/s 표시, F5 후 2/6 다리와 낮아진 몸체·물리적으로 떨어진 다리·0.65m/s 이동, R 초기화와 F4 후 5/6 상태를 확인했습니다. F4/F5가 렌더링 모드를 바꾸지 않는 것도 확인했습니다. 플레이어 사격 연결은 빌드로 확인했으며, 사격 명중의 UI 조작 검증은 이번 24개 검사에 포함하지 않습니다.

이 PC의 렌더링 실행에서 평균 약 59fps를 관찰했습니다. 복원한 외형으로 정상 5m/s 목표를 유지했습니다. 이는 한 장면의 관측값이며 외형 변경 전후 GPU 비용을 격리한 비교 벤치마크는 아닙니다. NullRHI 검사의 고정 60Hz 시간은 렌더링 성능 수치로 사용하지 않습니다.

## 방법론과 한계

현재 이동은 학습 정책이나 관절 힘으로 추진하는 방식이 아닌, 절차적 발 궤적·지형 IK·몸체 이동 제어입니다. 저자세의 몸통 지지 영역 역시 연출용 가상 영역이며 실제 배의 접촉력으로 균형을 푸는 시뮬레이션이 아닙니다. 분리된 부품만 Chaos 물리를 사용합니다. 원작의 애니메이션이나 구현과 동일하다고 주장하지 않습니다.

다리 간격 검사는 살아 있는 다리 사이에 적용됩니다. 떨어진 부품끼리 및 살아 있는 다리와의 물리 충돌은 안정성을 위해 제한되어 있어 잔해가 겹칠 수 있습니다. 큰 절벽·급회전·검증하지 않은 손실 조합에서는 도달 범위 또는 충돌 검사로 중단될 수 있습니다. 4족 고자세를 유지하려던 초기 구현은 앞다리 한 쌍 손실에서 지지·관절 범위를 위반해 최종판에서 저자세 전환으로 바꿨습니다. 실패 실험 기록은 v17_initial, v17_recovery, v17_masks, v17_transfer 폴더에 보존했습니다.
