# V13 보행 속도 개선

## 구현

기존 실제 관절 피드백과 한 다리씩 착지를 확인하는 보행을 유지하고, 보폭·보행 주기·착지 확인 시간·발 위치 제어 응답을 학습 변수로 추가했다. V12 정책에서 새 변수 4~7이 0이면 기존 제어값을 재현한다. 바디를 앞으로 순간 이동시키거나 외력을 더하지 않았다. 두 다리를 동시에 드는 보행은 아직 적용하지 않았다.

- 주기: `(2.8 + 0.4*g0) * (1 + 0.45*g4)` 초
- 중립 발 위치보다 앞에 놓는 거리: `(70 + 20*g1) * (1 + 0.9*g5)` cm
- 착지 확인: `0.15 + 0.1*g6` 초 (0.05~0.25초)
- 발 위치 피드백 이득: `3 + 1.8*g7`; 목표 관절 각속도 한계: `15 + 6*g7` 도/초
- 기존 발 들기 높이, 속도 감쇠, 관절 모터 강도도 학습한다. 전체 94개 슬롯 중 9개가 활성 변수다.

## 평가와 선발

완주·직립·실제 발 들기/착지·접지 일치 조건을 먼저 검사한다. 걸음 수는 최소 통과 조건이며 많이 걸었다는 이유로 추가 점수를 주지 않는다.

최종 보상(`v13_completion_time_plant_height`):

`완주 보너스 1000 - 소요 시간 - 40*평균 접지 변위 - 10*접지 발 중심 속도 - 5*접지 발 각속도 - 4*몸체 높이 RMSE² - 0.5*몸체 높이 표준편차² - 0.02*평균 기울기`

단위는 초, m, m/s, rad/s, 도다. 실패 개체는 -150점이며 번식에서 제외된다. 초기 비교/탐색의 `v13_completion_time_plant_drift` 보상에는 마지막 세 몸체 안정성 항이 없었으며 원자료에 보상 버전을 구분했다.

병렬 학습에서는 기존 V12 빠른형 측정치를 반올림한 상한을 추가한다: 평균 접지 변위 11.1cm, 최대 접지 변위 52.3cm, 접지 발 중심 속도 0.2165m/s, 발 최고 높이 1.5m 이하. 통과한 후보만 점수순 최대 4개를 부모로 사용한다. 전부 탈락하면 실패 유전자를 물려주지 않고 새 집단을 만든다. 30초는 성능 목표이며, 30초를 넘더라도 완주와 품질 조건을 만족하면 개선 학습의 부모가 될 수 있다.

접지 변위에는 착지 후 자리잡기와 구형 발의 굴림이 포함된다. 지형 레이와 구 반경으로 접지를 추정하며 힘 센서는 아니다. V12 안정형(평균 6.3cm)과 빠른형(평균 11.1cm)은 서로 다른 비교 기준이다.

## 실행 및 기록

각 후보마다 별도의 UE 프로세스와 물리 월드를 만들고 최대 2개를 동시에 실행한다. 고정 60fps, 최대 물리 서브스텝 1/120초 설정이다. 실제 학습은 가우시안 진화 탐색이며 신경망 PPO나 Isaac Lab 실행이 아니다.

새 영상 촬영은 하지 않는다. 정책 JSON, 세대별 후보 점수와 선발 목록, 엔진 로그, 독립 반복 검증을 남긴다. 이전 영상과 정책은 보존했다.

동일한 절차적 지형과 시작점에 대한 검증이며 다른 지형 시드, 다리 손실, 플레이어와의 전투를 검증한 결과는 아니다.

## 실제 결과

| 정책 | 5m 시간 | 평균 접지 변위 | 최대 접지 변위 |
|---|---:|---:|---:|
| V12 안정형 | 73.37초 | 6.31cm | 38.16cm |
| V12 빠른형 | 53.47초 | 11.10cm | 52.26cm |
| V13 속도 개선 | 27.38초 | 7.66cm | 41.51cm |

5m는 별도 프로세스에서 세 번 반복해 모두 30초 목표와 품질 조건을 만족했다. 세 반복의 측정값이 동일하다. 서로 다른 지형에 대한 일반화 검증을 의미하지 않는다.

선발 정책의 몸체 평균 높이 7.000m, 높이 표준편차 7.51cm, 평균 기울기 0.297도, 발 최고 높이 0.680m다. 한 다리 이동 슬롯 1.547초, 발 전방 배치 거리 119.0cm, 착지 확인 0.099초다.

총 48회 후보 평가(재평가 포함) 중 47회가 기본 5m 보행 조건을 통과했다. 추가 접지 품질 상한과 점수순 제한을 적용해 부모를 선발했으며, 독립 감사에서 잘못 선발된 부모는 0건이다. 후진하며 150초 제한을 넘긴 후보도 원자료에 남겼고 부모에서 제외했다. 두 프로세스 병렬 평가의 세 실행 총 벽시계 시간은 421.7초이며 빌드·코드 수정·반복/장거리 검증 시간은 포함하지 않는다.

- 15m 확장 검증(1회): 통과, 전방 변위 15.002m, 74.43초, 평균 접지 변위 12.04cm, 최대 44.75cm.
- 50m 확장 검증(1회): 실패, 전방 변위 13.734m, 140.93초, 평균 접지 변위 11.94cm, 최대 81.02cm.

## 재현

기존 안정형 실행기는 보존했다. 새 속도 정책 직접 실행: `Scripts/ReplaySpeedGait.ps1`. 영상은 촬영하지 않는다.

```powershell
python Scripts/TrainIsolatedGait.py --run new_speed_run --seed-policy LearningRuns/v13_verified/speed.json --workers 2 --population 10 --generations 3 --sigma .18
python Scripts/VerifyGait.py --policy LearningRuns/v13_verified/speed.json --run new_speed_verify --repeats 3
python Scripts/audit_gait.py LearningRuns/new_speed_run
```

원자료: `LearningRuns/v13_speed_sweep01`, `v13_speed_train01`, `v13_speed_final01`, `v13_verify_5m_01`. 검증 요약은 `docs/v13_verification.json`, 후보 비교표는 `docs/v13_candidates.csv`. UE 에디터 빌드, 보행 단계 판정과 실패 개체 번식 금지 자동 테스트 2개, Python 구문 검사, 실제 선발/보상 점수 감사가 통과했다.

## 장거리 결과의 한계와 다음 단계

15m는 기본 보행·완주 기준을 통과했으나 평균 접지 변위 12.04cm로 단거리 선발 상한 11.1cm를 초과했다. 동일한 접지 품질까지 통과했다고 해석하지 않는다. 50m는 140.93초에 제어 실패(`failed=true`)로 종료했고 종료 시점 전방 변위는 13.73m였다. 이는 최장 도달 거리가 아니다. 발 최고 높이 2.59m, 최대 접지 변위 81.02cm로 증가했다. 정확한 실패 원인을 구분하는 이벤트 기록은 아직 없다.

다음 작업은 장거리 구간에서 발판 선택과 접지 오차가 누적되는지 조사하고, 15m에서도 접지 품질 기준을 만족하도록 개선하는 것이다. 두 다리를 겹쳐 드는 보행은 그 이후에 검증한다.
